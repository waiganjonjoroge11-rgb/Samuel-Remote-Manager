# Samuel Remote Manager downloads

This folder is the central place in the project for published downloadable files and release notes.

- The website homepage is `index.html` at the repository root, so GitHub Pages opens the dashboard first.
- Account backups, CSV reports, GPS exports, camera photos, and audio recordings are generated from the signed-in dashboard and downloaded by the browser to the device's Downloads location (or the location selected by the browser).
- APK releases are published at the website root by the existing GitHub Actions deployment workflow.

Do not place private user records or credentials in this public folder.
